## 🛠 Persyaratan

Sebelum mulai, pastikan kamu sudah punya ini di komputer:

1.  **Node.js**: Wajib diinstall. [Download disini](https://nodejs.org/). Pilih versi "LTS" (v18 atau lebih baru).
2.  **Git**: Wajib diinstall. [Download disini](https://git-scm.com/downloads).
3.  **Twitter API**: Diperlukan untuk fitur auto-post (Key/Secret/Token dari Developer Portal Twitter).

## 📦 Instalasi (Cara Pasang)

Ikuti langkah-langkah ini perlahan untuk pemula:

### 1. Download Bot
Buka terminal (Command Prompt atau PowerShell) dan ketik perintah ini:

```bash
git clone https://github.com/sipaldrop/ArcBot-Sipal.git
cd ArcBot-Sipal
```

### 2. Install Aplikasi Pendukung
Masih di terminal, ketik perintah ini untuk menginstall semua kebutuhan bot:

```bash
npm install
```
*Tunggu sampai proses selesai. Mungkin butuh beberapa menit.*

## ⚙️ Konfigurasi (Pengaturan)

### 1. Buat File Akun (`accounts.json`)
Kamu perlu membuat file untuk menyimpan data akunmu.
1.  Cari file bernama `accounts_template.json` di folder bot.
2.  Ubah namanya menjadi `accounts.json`.
3.  Buka file tersebut dengan Notepad atau Text Editor.
4.  Isi data akunmu seperti format di bawah ini:

```json
[
  {
    "privateKey": "PRIVATE_KEY_METAMASK_MU",
    "proxy": "http://user:pass@ip:port",
    "AppKey": "TWITTER_API_KEY",
    "AppKeySecret": "TWITTER_API_SECRET",
    "AccessToken": "TWITTER_ACCESS_TOKEN",
    "AccessTokenSecret": "TWITTER_TOKEN_SECRET"
  }
]
```
> **Catatan:**
> - `privateKey`: Private key wallet Metamask kamu (Hati-hati jangan disebar!).
> - `proxy`: (Opsional) Jika pakai proxy, isi formatnya. Jika tidak, kosongkan atau hapus barisnya.
> - Data Twitter (`AppKey`, dll) wajib diisi untuk fitur auto-post.

### 2. Pengaturan Umum (`config.json`)
File `config.json` sudah diatur otomatis. Kamu tidak perlu mengubah apa-apa kecuali ada instruksi khusus dari update SipalDrop.
